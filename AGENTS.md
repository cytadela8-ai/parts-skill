# Project workflow

This is a solo project maintained by one person. Its requirements and implementation change
frequently, so work can generally be done directly on `main`.

- Working, committing, and pushing directly on `main` are allowed.
- Feature branches, worktrees, and pull requests are optional; use them when they help the task.
- This project-specific policy overrides general instructions requiring feature branches or
  prohibiting commits and pushes to `main`.
- Continue to preserve unrelated local changes, keep credentials and runtime data out of Git,
  and run checks appropriate to the change before committing.
